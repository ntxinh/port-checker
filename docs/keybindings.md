# Keybindings
| Key | Action |
|---|---|
| `↑`/`k`, `↓`/`j` | navigate |
| `enter` / `x` | SIGTERM selected port's owner (confirm) |
| `y` | confirm kill · `n` / `q` / `esc` cancel |
| `K` | SIGKILL last-SIGTERM'd PID if still alive |
| `/` | filter by port or process name (`enter` applies, `esc` clears) |
| `s` | cycle sort: port → pid → process |
| `r` | refresh now |
| `q` / `ctrl+c` | quit (`ctrl+c` works from any state) |
