# port-checker
Go + Bubble Tea TUI listing open ports and killing their owners.

## Run
```sh
mise install && make run
```

## Keybindings
See [docs/keybindings.md](docs/keybindings.md). Core: `enter`/`x` kill (confirm → SIGTERM), `K` force-kill, `/` filter, `s` sort, `r` refresh, `q` quit.
